# E-Commerse Sales Analysis Visualization Using Yandex Datalens
A study project using synthetic data on sales on a marketlplace

### Project Overview
This project is the practice part of the course available from [Stepik Course](https://stepik.org/course/216086/syllabus). It uses synthetic data to calculate and follow the major metrics of a dataset from a marketplace.

### Data Sources
[Stepik Course](https://stepik.org/course/216086/syllabus)
